# 调查回避分派

联合调查办公室将施工质量线索分派给外部核验组时，系统自动执行利益冲突回避、
双资质组队、容量与跨区权衡、负责人双重复核及调查中撤换留痕。

日期按本地自然日表示（`YYYY-MM-DD`），履历中的起止日均包含在有效区间。

## 业务规则

### 三类回避关系分别判定

每条人员-工程关系按类型独立判定，互不合流、不可省略：

| 关系类型 `kind` | 含义 | 窗口判定 |
| --- | --- | --- |
| `employment` | 曾在该工程任职 | 任职闭区间 `[effective_date, end_date]` 与调查窗口含端点重叠即回避 |
| `kin_declaration` | 近亲属从业申报 | 申报受理日 `effective_date` 落入窗口（含端点）才回避 |
| `acceptance_signoff` | 曾签署验收意见 | 签署日落入窗口（含端点）才回避 |

只统计与本案 `project_id` 相同的关系；窗口外的同工程关系保留在
`outside_window` 中供解释，**既不扩大回避也不隐藏**。

### 组队硬约束与偏好

* 每案必须覆盖 `site_tech`（现场技术）与 `material_review`（材料审查）两类资质，
  且两岗位由不同人员担任；
* 硬约束：资质匹配、三类窗口内回避均无命中、在担量 + 本案分工 ≤ 个人容量；
* 软偏好（可解释打分）：跨区支援人数 × 紧急权重（normal=1 / urgent=2 / critical=3）
  优先最小，其次按边际负载 `2×在担+1` 把任务分给余量更大的人员；
* 无合格组合时，按 Hall 定理返回**包含最小的违约岗位集合**
  （最小约束核），并逐人列出排除原因（缺资质 / 被哪类关系回避 / 容量不足），
  附三类关系的全量核查痕迹 `recusal_trace`。系统不会为了凑齐组合而放宽任何回避。

### 确认复核与并发

* 方案生成时固化所涉人员的**关系版本**（全部关系记录的哈希）；
* 负责人确认时再次核对：关系版本、资质、窗口内回避、剩余容量，任一不符返回
  `409` 及具体差异码（`relation_version_stale` / `client_version_stale` /
  `recusal_changed` / `capacity_conflict` 等），须重新生成方案；
* 确认全程持锁：两位负责人同时确认竞争同一人员的两个方案，**只成功一个**，
  失败方得到容量冲突及竞争案件清单。

### 调查中新发现利益关系

* 登记新关系后，系统对同工程在担案件重判：窗口内命中立即撤换（`removed`），
  窗口外只留痕（`not_recused_outside_window`），不静默；
* 撤换自动生成**仅补空缺岗位**的替换方案（未受影响岗位固定），负责人再次确认；
* 历史意见原件保留，被撤换人此前出具的意见标记为 `needs_recheck` 并注明
  须重新核验的覆盖部分；新在任人员重新出具的意见独立登记。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康探针 |
| GET | `/persons` | 人员履历、关系版本、当前在担量 |
| GET | `/cases` / `/cases/{id}` | 案件清单 / 案件全貌（分工、意见、待确认方案） |
| POST | `/cases/{id}/plans` | 生成分工方案（含逐条选择理由或最小约束核诊断） |
| POST | `/cases/{id}/confirmations` | 负责人确认，body：`reviewer`、可选 `expected_versions` |
| POST | `/persons/{id}/relations` | 登记新发现关系，body：`{"link": {...}}`，触发撤换与补位 |
| POST | `/cases/{id}/opinions` | 在任人员登记核验意见 |

未知接口返回 404；契约/参数错误返回 400；状态冲突返回 409，响应均含机器可读 `code`。

业务数据格式位于 `contracts.py`，示例数据位于 `data/`（虚构编号，不含个人联系方式）。

## 本地开发

```sh
python3 -m unittest discover -s tests -v
python3 service.py
```

服务默认监听 8080，可用 `PORT` 调整；数据路径可用 `PERSONS_FILE`、`CASES_FILE`
环境变量覆盖。数据结构验证不会推断记录的业务结论。
